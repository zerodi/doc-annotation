# Doc Annotation

- Просмотр страниц документа с масштабированием (`Zoom In/Out` в шапке).
- Добавление аннотации через ЛКМ:
  - одиночное нажатие создает небольшой блок;
  - при зажатии можно установить размер.
- Перемещение аннотаций внутри страницы (только внутри кадра).
- Ресайз аннотации снизу‑справа, сохраняется положение и размер.
- Удаление аннотации.
- Сохранение - кнопка `Save` логирует в консоль структуру документа и все аннотации.

## Плюсы
- У аннотации есть отступ сверху для удобства восприятия оригинального содержимого и текста аннотации.
- Координаты хранятся относительно страницы — масштабирование не ломает позиционирование.
- Простая расширяемость: аннотации/выделения унифицированы одним компонентом.

## Минусы
- Нет валидации содержимого аннотаций.
- Тесты не покрывают интерактивные сценарии (drag/resize/create).
- При создании аннотации не переходит редактирование на новый элемент
- Размер аннотаций при изменении масштаба страниц (не в Проблемах, поскольку пока не вижу оптимального решения для сохранения позиции и размера аннотации с сохранением читаемости текста)

## Проблемы
- Отсутствует мобильная верстка, Позиционирование страниц при изменении масштаба - требуется доработка верстки
- Сильная связность аннотаций со страницами:
  - Сделать компонент аннотации глупым - только отображение и размер
  - Позиционирование и задание размера реализовать через директивы
  - Отделить состояние модели от компонента страниц
